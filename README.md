## 你可以往这里放的东西

| 文件夹 | 放什么 | 命名建议 |
| --- | --- | --- |
| `assets/images/projects/` | 项目截图、流程图、团队照片 | `cstar-1.png`、`bitazone-flow.png` |
| `assets/images/art/` | 插画、贴纸、角色设计 | `sticker-01.png` |
| `assets/resume/` | 简历 PDF | `Mu-Shan-Rau-Resume.pdf` |

图片建议：宽度 1600px 左右，单张小于 1 MB，用 PNG 或 JPG。
