DrippyDrop  
DrippyDrop is a character of melting ice. It is designed to be a sticker theme that can be used under different circumstances.  
I designed different sticker, including "love you", "Mid-Autumn Festival", "Awww", "good night", and "fighting" for different uses.  
The sticker collection is still under development.
